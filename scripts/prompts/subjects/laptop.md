CONTEXT:
This icon represents **coding / frontend development education**
(a bootcamp / training program), not a generic device or a web product.
It is used next to a short "교육" (education/training) text entry,
so the silhouette must read as "a laptop for writing code" at a glance.

SUBJECT:
A physical open laptop computer (clamshell form — screen + keyboard base).

The silhouette must immediately read as an open laptop,
even when rendered at 48–64px.

  tilted open at roughly 100–110 degrees
- 3/4 perspective so both the screen face and the keyboard deck are visible
- softly rounded corners and edges on both the base and the screen
- visible base thickness
- simple physical laptop silhouette — not a generic slab

Add only minimal laptop cues:
- a subtle simplified keyboard/trackpad texture on the base (soft rows or a
  faint grid, not individual readable keys)
- optionally, on the screen, 2–3 small soft rounded blocks suggesting a code
  editor layout (e.g. a thin sidebar + a couple of short line shapes) —
  extremely abstract, never actual readable text or a real UI mockup

- subtle refraction
- soft specular highlights

- a dashboard or app screen mockup
- any readable text, code, or real UI

WEB = flat browser window.
MOBILE = physical smartphone.
LAPTOP = physical open clamshell laptop (screen + keyboard base, seen at an angle).

These three concepts must remain visually distinguishable
even at small icon sizes.
