# 이번 생성 대상: email

**Primary concept**: envelope / message

**방향**: rounded translucent glass envelope + warm-white paper/letter element peeking out from inside, 또는 봉투 앞면의 작은 pale-blue seal/dot 하나.

우편함, 실제 이메일 앱 UI, "@" 기호를 문자처럼 표현하는 것을 만들지 않는다. envelope 하나를 중심으로 한다. 작은 크기에서도 "email/contact"라는 의미가 즉시 읽혀야 한다.
